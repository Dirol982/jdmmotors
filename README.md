# jdmmotors

Редизайн главной страницы [jdmmotors.by](https://jdmmotors.by/) — автосервиса Toyota и Lexus в Минске.

Статический сайт без сборки: `index.html`, `styles.css`, `main.js`, фото в `assets/img` (взяты с текущего сайта и пережаты в WebP). Публикуется через GitHub Pages из корня репозитория.

Локальный просмотр:

```bash
python3 -m http.server 8000
```

Форма записи работает без сервера: проверяет поля и собирает заявку в SMS на +375 29 633-33-96 (плюс кнопки «Скопировать» и «Позвонить»). Чтобы заявки приходили автоматически, подключите обработчик формы (например, Telegram-бота или Formspree) в `main.js`.

Дизайн-система описана в `DESIGN.md`, факты о продукте — в `PRODUCT.md`.
